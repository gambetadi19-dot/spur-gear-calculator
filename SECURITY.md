# Security Policy

## Supported Versions
Currently supported security release line:
- `1.0.x`

## Reporting a Vulnerability
If you discover a security issue, please report it privately before public disclosure.

Please include:
- Affected version
- Reproduction steps
- Impact assessment
- Suggested fix (if available)

## Response Process
- Acknowledgement target: within 3 business days
- Initial severity assessment: within 7 business days
- Fix timeline:
  - Critical: expedited patch release
  - High/Medium: next scheduled patch/minor release

## Disclosure Policy
- Do not publish proof-of-concept details until a fix is available.
- Coordinated disclosure is preferred.

## Scope Notes
This is a desktop application. Typical concerns include:
- Unsafe file handling during exports
- Dependency vulnerabilities
- Malicious input causing instability

All reports are appreciated and will be handled respectfully.
