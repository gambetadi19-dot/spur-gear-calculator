# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-04-22
### Added
- CustomTkinter professional dashboard UI.
- Collapsible/expandable workspace panels and focus modes.
- Gear preview with zoom, pan, fit, reset.
- Precision geometry annotation alignment.
- Exports: CSV, PDF, preview PNG, copy results.
- Help/About dialog with formulas and assumptions.
- Version and units metadata in UI and exports.
- Gear logo window icon support.

### Improved
- Input validation and conflict messaging.
- Engineering checks with PASS/WARNING/ERROR style outputs.
- Export error handling robustness.
- Preview fit behavior and recovery.

### Release Status
- v1.0.0 approved for release.
