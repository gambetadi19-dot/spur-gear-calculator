# Support

## Getting Help
If you run into issues using Spur Gear Engineering Calculator, please include:
- App version (for this release: `v1.0`)
- Operating system
- Steps to reproduce
- Input values used
- Error message text
- Screenshot (if layout/preview related)

## Issue Types
- Bug report: incorrect behavior, crash, export failure.
- Feature request: new functionality or workflow enhancement.
- Engineering clarification: formula/assumption question.

## Response Guidance
- Triage target: within 2 business days.
- Critical bug (data loss/crash): priority handling.
- Non-critical UI polish: scheduled in minor releases.

## Temporary Workarounds
- Preview misplaced after heavy zoom/pan: click `Fit` or `Reset`.
- PNG export not available: install dependencies from `requirements.txt`.
- Input conflicts: remove conflicting dimensions and solve with a valid pair.
